--- For Build 1 ------------------------------------------------------------
Wiring a variable font into @font-face just needs a weight RANGE, e.g.:
  @font-face {
    font-family: 'Source Serif 4';
    src: url('assets/fonts/source-serif-4/SourceSerif4-VF.ttf') format('truetype-variations');
    font-weight: 200 900;
  }
  @font-face {
    font-family: 'Source Serif 4';
    font-style: italic;
    src: url('assets/fonts/source-serif-4/SourceSerif4-Italic-VF.ttf') format('truetype-variations');
    font-weight: 200 900;
  }
(same pattern for Open Sans; IBM Plex Mono's two files are already
single-weight statics, so a plain font-weight: 400 / 500 @font-face each is
enough — no range needed.)
