    About 837 Claim Viewer
    Version Build date
    The claim file you opened is never written to — every form preview and PDF render happens fully in memory, and closing a tab drops its parsed claim from memory immediately. The file paths of your open tabs and a capped recent-files list are saved on this machine, so the app can restore your tabs next time it starts. If you use Edit fields to correct a value, that correction is saved on this machine too (separately from the original file, which stays untouched) so it's there next time you open the same claim — every edited value stays visibly marked, and any export built from an edited claim is stamped EDITED, in every export format. Batch PDF, combined-PDF, CSV and JSON exports all write only to a location you choose; CSV/JSON exports exclude patient identifiers (name, date of birth, address, full member ID) unless you explicitly check "Include patient identifiers" in the export dialog. A file or folder name can be PHI-adjacent — use File → Forget open tabs & recent files to clear that trail at any time. Runs fully offline; nothing ever leaves this machine.
    Forget open tabs & recent files?

    This clears the saved list of currently-open tabs and the recently-opened-files list stored on this machine. Tabs open in this window right now stay open — they just won’t come back automatically next launch. This never touches an exported PDF or the claim file itself.
