# Build-plan expert review — 2026-07-27

_86 findings from 14 expert reviewers. PHI/compliance objections were explicitly out of scope._

## Verdict
Not yet safe to run unattended. The plan's entire recovery model ("leave the tree at the last green state", "checkpoint", "never compound a failure") is fictional — the repo is not a git repository, so a bad subagent rewrite of the 1,604-line src/renderer/main.ts at 03:00 is unrecoverable and the morning review has no diffs. With a ~45-minute Build 0 done before 22:00 (git init + baseline tag, verify:fast split, BUILD_LOG.md, large fixtures, fonts pre-downloaded) plus about a dozen doc edits, Build 1 and probably Builds 2-3 are a realistic and worthwhile night. The single biggest risk after git is the contradiction between BUILD_QUEUE rule 4 and TABS guardrail 8: as written it forbids most of Build 3 and 4, and an unattended agent will either refuse the work or decide guardrails are advisory — which removes the only protection over six real prior bug fixes.
